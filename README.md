# MacWallpaper

> 一个零依赖的 MacBook 刘海屏壁纸制作工具 —— 上传壁纸，把顶部刘海区域"涂黑隐藏"，让 MacBook 的刘海在视觉上消失。

MacBook Pro / Air 的屏幕刘海会打断壁纸的视觉完整性。MacWallpaper 自动生成适配刘海屏的壁纸：**顶部刘海+菜单栏区域被涂成黑色，原壁纸整体下移（不裁切顶部内容）**。设为桌面壁纸后，黑色区域与屏幕刘海、菜单栏融为一体，刘海视觉上"消失"。

所有图片处理均在**浏览器本地**完成，不上传任何数据，无需联网，无需安装任何依赖。

## 特性

- 支持 MacBook Pro 14"/16"、MacBook Air 13"/15" 四款刘海机型，按原生分辨率导出
- 默认黑条高度按各机型自身结构精确推导（屏高 − 16:10 区域），左侧栏展示刘海实测尺寸
- 上传后先预览原图，确认后再生成成品（拖拽上传可跳过确认直达预览）
- 预览画布按住拖动平移画面，所见即所得，导出结果与预览一致
- 手动缩放滑块 + 一键「填充」，消除底部/侧边黑边
- 九宫格吸附：画面可对齐边界（左/右/上/下）或中心
- 黑条高度可微调
- 导出格式可选 PNG（无损）或 JPG（体积约为 PNG 的 1/10），文件名自动命名为「原文件名-机型名」
- 加载/生成/导出均有进度指示，导出期间防重复点击
- 纯 HTML + CSS + 原生 JavaScript（Canvas API），零第三方依赖

## 快速开始

无需安装任何依赖，克隆仓库后双击打开 `index.html` 即可使用（任意现代桌面浏览器：Chrome / Edge / Safari / Firefox）：

```bash
git clone https://github.com/<your-username>/MacWallpaper.git
cd MacWallpaper
# 双击 index.html 或拖入浏览器打开
```

也可以直接下载本仓库的 `index.html` 单文件，放到任意位置打开。

## 使用方法

1. 在左侧选择你的 MacBook 机型
2. 点击或拖拽上传壁纸图片（拖拽直接进预览，点击需先确认原图）
3. 按需调整：
   - **拖动画面**：在预览图上按住拖动，调整放大后的取舍区域
   - **缩放**：左侧滑块手动放大，或点「填充」一键放大到刚好铺满
   - **吸附**：九宫格快速对齐边界或中心
   - **黑条高度**：默认值已按机型推导，一般无需改动
4. 选择导出格式（PNG / JPG），点「下载壁纸」
5. 在 macOS「系统设置 → 壁纸」中选择导出的图片即可

## 常见问题

**为什么 MacBook Pro 14" 和 16" 的默认黑条高度都是 74 px？**

两款机型的 macOS 菜单栏同为 37 pt（@2x = 74 px），默认黑条高度按各机型「屏高 − 16:10 区域」独立推导，数值相同属正常现象。Air 机型切换为 64 px。

**PNG 和 JPG 怎么选？**

- PNG：无损，适合插画/渐变类壁纸，文件较大（3024×1964 约 1~3 MB）
- JPG：0.92 高质量有损压缩，适合照片类壁纸，体积约为 PNG 的 1/10，黑条区为纯黑几乎无压缩痕迹

**导出的图片为什么顶部有一条黑边？**

这正是设计目的——黑色区域对应屏幕刘海与菜单栏的位置，设为壁纸后与屏幕黑色刘海无缝融合。

## 隐私说明
